# Browser
A tiny Android browser.

## Features
 - Multi-tab browsing
 - Resource sniffing for video and audio capture
 - User-Agent switching between mobile and desktop modes
 - View source code via view-source protocol
 - Fast and lightweight

## Compatibility
Requires Android 5.0 or higher.

## Download
Get the APK from the Releases page.

## Build from Source
 1. Clone this repository `git clone https://github.com/Gao-myapp/Browser.git`.
 2. Install the Android SDK.
 3. Run `./gradlew`.
